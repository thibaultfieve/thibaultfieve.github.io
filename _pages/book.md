## Why this book

Manufacturing plants produce large volumes of cost and operations data in their ERP systems. Yet much of the financial controlling work built on that data is still manual: exporting tables, rebuilding spreadsheets, and checking variances by hand. This slows down decisions and leaves less time for analysis.

This book offers a practical, reproducible way to automate that work. It is written for finance and controlling professionals, analysts, and students who want to move from manual reporting to automated, data-driven cost control.

## The M-FAME framework

The book introduces **M-FAME**, a framework built around five modules:

1. **ERP data integration**: extracting and structuring cost, production, and purchasing data.
2. **Workflow automation**: automating recurring reports and the financial close.
3. **Financial intelligence**: variance analysis, cost modeling, and forecasting.
4. **AI agent layer**: using AI agents to support controllers in routine tasks, under human review.
5. **Performance measurement**: measuring time saved, data quality, and decision impact.

## Structure

Twelve chapters in four parts:

- **Part I: Foundations**: manufacturing finance, ERP data, and cost controlling.
- **Part II: Methods and Implementation**: data pipelines, report automation, and variance analytics.
- **Part III: Intelligent Systems**: machine learning and AI agents for finance operations.
- **Part IV: Evaluation and Scalability**: an applied case study, measurement, and the full M-FAME framework.

Each chapter follows the same path: concepts, mathematical formulation, Python implementation, a hands-on lab, results, and exercises.

## Hands-on labs

All labs use **NovaCos Manufacturing Inc.**, a fictional US cosmetics plant with 16 production lines and 24 months of simulated ERP data. The dataset is **fully synthetic**, so readers can run every example without access to a real company's systems. Notebooks and data will be shared in a public GitHub repository.
